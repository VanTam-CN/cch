# Roadmap

This roadmap describes direction, not delivery commitments.

## Current public preview

- Governed knowledge and deterministic context compilation.
- Document ingestion and source locators.
- Asset discovery, frozen model exchange, and deterministic retrieval.
- Evidence packages, maps, structured storyboards, and verification receipts.
- Local web interface.
- Optional, experimental Hindsight shadow adapter.

## Next priorities

1. Improve source installation, errors, and examples using actual user feedback.
2. Make knowledge, assets, and evidence easier for external agents and skills to consume.
3. Exercise the interfaces on additional synthetic and independently reviewed tasks.
4. Qualify a live memory provider before implementing unified context assembly.
5. Keep memory-to-cognition promotion behind source lookup and human approval.

Final document rendering, an autonomous approval authority, and an unauthenticated
shared web service are outside the public project's scope.
