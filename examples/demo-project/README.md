# Synthetic knowledge base

This read-only example contains 40 fictional objects: one governing rule,
three configuration records, and 36 filler records. The filler records make
selection visible; they are not evidence of retrieval quality on real projects.

Current pool limit `200`, tentative trial `100`, and superseded `150` all describe
a made-up project. Compile them with the command in [QUICKSTART](../../QUICKSTART.md).

Regenerate the fixture with `tools/make_examples.py`. No original project,
private knowledge store, or business document was used.
